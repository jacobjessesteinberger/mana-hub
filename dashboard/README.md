# Dashboard Map

The production dashboard lives in `src/app/dashboard/agents/`.

Course-relevant surfaces:

- `src/app/dashboard/agents/page.tsx` for the overview.
- `src/app/dashboard/agents/[name]/chat/page.tsx` for agent chat, attachments, edit/retract, and `/stop`.
- `src/app/dashboard/agents/projects/` for Workspaces.
- `src/app/dashboard/agents/goals/` for Outcomes.
- `src/app/dashboard/agents/issues/` for Tasks.
- `src/app/dashboard/agents/approvals/` for Risk Approval.
- `src/app/dashboard/agents/knowledge/` for Knowledge Base previews.
- `src/app/dashboard/agents/docs/page.tsx` for in-app product documentation.

This folder is a map only, not a duplicate dashboard implementation.
