# User Config

Files in this folder belong to the installer and are ignored by git.

Copy the example files and remove `.example`:

```bash
cp user.config/agents.example.json user.config/agents.json
cp user.config/branding.example.json user.config/branding.json
cp user.config/integrations.example.json user.config/integrations.json
```

Mana Hub updates should never overwrite your real files in this folder.
